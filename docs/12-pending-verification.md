## B 待验证（按优先级）

### B1 局域网发现（S-4 / P1-08）——0.9.21 起

**怎么验**

1. 电脑端开启局域网访问，手机与电脑同一 Wi-Fi；
2. 打开 App 首页，看「附近的电脑」；
3. 点列表里的电脑（已配对过）。

**判定**：列表出现电脑名称与 `https://<IP>:3443`；点击后直接进入页面，不要求扫码。

**失败时看什么**：「附近的电脑」下方最近 3 行日志——

- 列表为空且无日志 → 没发现（Bonjour/权限问题）；
- `ignored <名字>: announcement …` → 公告不符合契约（键集、protocol、instanceId、origin 主机不匹配）。

**已知限制**：发现只用于「已配对」的电脑；未配对的会显示「未配对」，仍需扫码（公告里没有配对 token）。

### B2 远程通道（P0-03）——未开始

**怎么验**

1. 电脑端起一条隧道（cloudflared 命名隧道或同等物），拿到 `https://<域名>`；
2. App 里用该地址的配对链接配对（注意：隧道 origin 是 https，但**不需要**私有 CA）；
3. 关掉 Wi-Fi、用蜂窝网络，重新打开页面。

**判定**：配对成功、页面可加载、`native-renew` 正常；切换网络后能自动恢复。

**失败时看什么**：桥日志 `gateway load failed` 的 NSError 码；配对日志里的 CA 步骤（隧道下 `/ca.cer` 可能 404，属正常）。

### B3 手动地址输入（P1-09）——代码已有，未单独验

**怎么验**：首页输入框粘贴 `https://<IP>:<端口>`（不带 token）→ 点「解析」→ 应显示 origin 但提示无 token；再粘贴完整配对链接 → 配对成功。

**判定**：裸 Origin 被识别为「可解析但不可配对」；非法输入（`http://`、带路径、带账号）被拒绝且不崩溃。

### B4 相机剩余用例（C-9 / C-10 / C-11）——见 [09](09-camera-test-plan.md)

| 用例 | 怎么验 | 判定 |
| --- | --- | --- |
| C-9 超大图 | 拍一张高细节照片 | 超过 8 MiB 回 `payload_too_large`；未超则正常 |
| C-10 超时 | 临时把 `CameraCapture.deadline` 改成 10 s，进相机后不操作 | 到点自动关闭并回 `timeout`；测完改回 60 |
| C-11 无相机 | 模拟器（无相机）点相机 | 回 `unavailable`，不崩溃 |

### B5 文件选择超时（0.9.20 起 305 s）

**怎么验**：点附件 → 选文件 → 在系统选择器里停留 **超过 60 秒** 再选。

**判定**：不再出现 JS 侧 `timeout`，选择照常完成（0.9.20 前会在一分钟时超时）。

### B6 `auth.renew` 被拒时的页面行为（0.9.20 / 0.9.22 起）

**怎么验**：电脑端移除设备 → 在已打开的页面里触发一次续期（页面通常自动触发，或切后台再回来）。

**判定**：桥日志出现 `reply failed device_revoked`（而不是 `failed`），页面停止重试并提示重新连接。

### B7 续期取消（0.9.22 起）

**怎么验**：在页面触发续期后立刻切走/让页面 abort（例如快速切换会话）。

**判定**：桥日志出现 `auth.renew cancelled`，随后 `reply failed cancelled`；没有长时间挂起的请求。

### B8 文件回执形状（0.9.22 起）

**怎么验**：拍照或选文件 → 附件出现在输入框 → 发送成功。

**判定**：附件正常渲染（不再是坏图/空文件）。这是扁平回执改动的回归点。

### B9 iOS 17 与 iPad（P7）

**怎么验**：在 iOS 17.x 设备与 iPad 上跑一遍「配对 → 打开页面 → 拍照 → 选文件」。

**判定**：与主力机一致；布局在横竖屏、分屏下不破。

### B10 7 天重签（P1-11）

**怎么验**：等签名过期 → 重签覆盖安装（不卸载）→ 打开 App。

**判定**：设备列表与配对保留，无需重新配对。
